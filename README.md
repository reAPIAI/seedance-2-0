# Seedance 2.0 via reAPI

Agent skill for generate videos with reAPI using Seedance 2.0 (`doubao-seedance-2.0`).

Install with skills.sh:

```bash
npx skills add https://github.com/reAPIAI/seedance-2-0 --skill seedance-2-0
```

Set your reAPI key:

```bash
export REAPI_API_KEY="rk_live_xxx"
```

Then use the skill in Claude Code, Codex, Cursor, or another compatible agent.
